# 연이음 시각 방향

2026-11-12. 사용자 선택은 **흑백·회색의 단정한 미니멀 화면**이다. 배경 #f6f6f6, 카드 #ffffff, 본문·주요 버튼 #202020, 보조 글자 #666666, 메뉴 #171717을 사용한다. 상태는 색상만으로 구분하지 않고 문구와 명암으로 표시한다.

학교 로고와 커너비는 사용자가 제공한 PNG 원본을 그대로 복사했다. 자르기·색 변경·배경 제거·재그리기를 하지 않았다. 학교 로고는 학교 표시에, 커너비는 로그인 안내에 사용하고 원래 색상을 유지한다. 연이음의 서비스 표기는 우선 흑백 워드마크다. 별도의 서비스 심볼은 최종 확정하지 않았다.

- `apps/web/public/brand/university-symbol.png`: 사용자 제공 ui_01_1.png
- `apps/web/public/brand/cornbee.png`: 사용자 제공 9DECAC.png

학교 표시와 서비스 이름·안내 캐릭터를 구분해 배치한다. 자료·회계 등 주요 업무 화면에는 캐릭터를 반복 배치하지 않는다.

로고 조합 비교는 개발 서버의 `/brand.html`에서 확인한다. A 워드마크, B 학교 심볼 결합, C 커너비 결합은 선택용 시안이며 현재 A를 임시 적용했다. 이 비교 문서는 개발용 페이지이고 기본 앱 빌드의 진입점은 아니다.
