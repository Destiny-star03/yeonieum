# 연이음 시각 방향

2026-11-12 사용자 확정: **B안 — 학교 심볼 + 연이음**. 서체는 최신 선택인 Pretendard, 색상은 제공한 ‘고요한 리넨’ 팔레트를 따른다. 앞선 흑백 팔레트·A안 임시 적용은 이번 선택으로 대체한다.

| 용도 | 색상 |
|---|---|
| 기본 배경 | #F7F3EE |
| 보조 면·배지 | #E6DED4 |
| 사이드바·대시보드 카드·구분선 | #C9BFB4 |
| 보조 글자·그래프 | #6B625B |
| 본문·주요 버튼 | #1F1D1B |

메인 작업 면과 폼 패널은 같은 계열의 밝은 #FFFDF9를 사용한다. 밝은 두 배경을 구분하고 주요 텍스트에는 짙은 색을 사용한다. 상태는 색상만으로 구분하지 않고 문구·명암을 함께 쓴다.

학교 로고와 커너비는 사용자가 제공한 PNG 원본이다. 자르기·색 변경·배경 제거·재그리기를 하지 않았다. 학교 심볼은 연이음 워드마크와 결합하고, 커너비는 로그인 안내에 원래 색상으로 사용한다.

- `apps/web/public/brand/university-symbol.png`: 사용자 제공 ui_01_1.png
- `apps/web/public/brand/cornbee.png`: 사용자 제공 9DECAC.png

## 서체와 대시보드 구성

최신 사용자 선택으로 서체를 **Pretendard v1.3.9**로 변경했다. 이전 나눔스퀘어라운드 선택은 대체한다. 공식 가변 웹폰트를 로컬에 포함하고 `apps/web/public/fonts/pretendard/LICENSE.txt`에 원본 라이선스를 보존한다. 외부 CDN 없이 표시하며 로고 700~800·제목 600~700·본문 400을 사용한다.

- [Pretendard 공식 저장소](https://github.com/orioncactus/pretendard/tree/v1.3.9)

사용자 참고 디자인처럼 밝은 토프색 사이드바, 둥근 회색 카드, 상단 일정 선 그래프와 역할 상태 도넛, 요약 지표, 하단 두 개의 표로 구성한다. 그래프와 지표는 서버가 현재 사용자에게 허용한 담당자·역할 자료만 집계한다. 임기 일정은 등록된 기간이며 실제 접속·업무 활동 이력으로 표현하지 않는다. 아직 구현하지 않은 예산·지출의 임의 금액을 대시보드에 채우지 않는다.

`/brand.html`은 확정된 B안 로고와 리넨 팔레트 확인 페이지다.
