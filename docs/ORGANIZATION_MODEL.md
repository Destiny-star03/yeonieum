# 연이음 조직 구조·운영 주체

버전 0.7 / 2026-11-12, Asia/Seoul. 근거는 사용자가 직접 설명한 학교 운영 구조와 상세 직책·권한 부여 설명(S7, S9, S10~S12)이다. 최신 사용자 Q1~54·DM-C01/02의 관계·범위는 [도메인 모델](DOMAIN_MODEL.md)을 따른다. 공식 규정·학교 승인을 별도 검증했다는 뜻은 아니다.

## 1. 확인된 사실

- 학교: 연암공과대학교.
- 학생자치기구는 총학생회·학과협의회·신문방송국·연합동아리의 4개 단체다.
- 각 단체에 최고 책임자 1명이 있고, 그 아래 구성은 단체마다 다르다. 아래 표와 관계도는 S9의 상세 설명을 반영한다.
- 학생성공센터 담당 선생님이 포털의 관리자다. 각 단체 최고 책임자 권한을 부여한다.
- 첫 버전은 담당자 중심으로 사용하며, 최고 책임자는 자기 단체의 하위 역할을 부여할 수 있다.
- 예산은 각 단체의 최고 책임자가 보유하거나 관리한다.
- 학회장은 부학회장·반대표 역할을 직접 부여한다. 반대표 담당 범위는 학과→학년→반으로 구분한다(DM-C01).
- 의장(학과협의회장)은 자기 학과의 학회장을 겸한다. 의장과 그가 맡고 있는 자기 학과의 학회장은 동일 인물이며, 학회장들이 이미 학회장으로 정해진 사람들 중 투표로 의장을 선출하며, 의장은 두 직책을 같은 공식 임기로 맡는다(DM-C05). 자기 학과 학회장 자격이 종료되면 의장도 종료한다(DM-C02).

| 단체 | 최고 책임자 직책 | 하위 구성 | 확인된 예산 책임 |
|---|---|---|---|
| 총학생회 | 학생회장 | 부장 → 차장 | 최고 책임자가 보유 또는 관리 |
| 학과협의회 | 의장 | 학회장 → 부학회장 → 반대표 | 최고 책임자가 보유 또는 관리 |
| 신문방송국 | 국장 | 부장 → 차장 | 최고 책임자가 보유 또는 관리 |
| 연합동아리 | 연합동아리장 | 일반동아리장 → 동아리원 | 최고 책임자가 보유 또는 관리 |

## 2. 관계도

아래는 조직의 구성 관계다. 별도로, S10에서 역할 부여 흐름은 담당 선생님→4개 최고 책임자→각 단체 하위 담당자로 확정했다. S11에서 학회장→부학회장·반대표 역할 부여를 추가 확정했고, 그 밖의 하위 담당자 재위임은 첫 버전 제외다. 직책 자체가 자료·회계 권한을 자동 부여하지 않는다. 의장은 자기 학과 학회장을 겸한다(S12). [역할·권한 명세](ACCESS_CONTROL.md)를 함께 참조한다.

```text
연암공과대학교
└─ 학생성공센터 — 담당 선생님
   ├─ 담당: 총학생회
   │        └─ 학생회장
   │           └─ 부장
   │              └─ 차장
   ├─ 담당: 학과협의회
   │        └─ 의장 (자기 학과 학회장 겸임)
   │           └─ 학회장
   │              └─ 부학회장
   │                 └─ 반대표
   ├─ 담당: 신문방송국
   │        └─ 국장
   │           └─ 부장
   │              └─ 차장
   └─ 담당: 연합동아리
            └─ 연합동아리장
               └─ 일반동아리장
                  └─ 동아리원
```

직책의 연결 순서는 사용자 설명대로 확인했다. 반대표의 학과→학년→반 범위는 확인했다. 같은 반 이름이라도 학과·학년이 다르면 다르다. 실제 소속 목록·직책별 인원수·부서 배치·개별 동아리의 세부 권한 경계는 O-13이다. 위 연결을 지출 승인 순서나 상위 직책의 모든 하위 자료 열람권으로 해석하지 않는다. 네 단체의 관계를 총학생회 산하 구조로 가정하지 않는다.

## 4. 데이터·권한 설계 제안

- 의장(학과협의회장)과 자기 학과 학회장은 동일인의 겸임이다. 두 역할의 담당 범위·권한 부여 기록은 구분하고 공식 임기는 같게 표현한다. 실제 선출은 학회장들의 투표, 서비스 역할 부여는 담당 선생님의 업무다. 자기 학과 학회장 자격이 끝나면 의장도 종료한다. 중도 사임·재선출·대행 등 예외 절차는 DM-O04다. 선생님의 단독 지명을 실제 의장 선출로 바꾸지 않는다.
- 직책과 시스템 권한을 구분한다. 단체별 직책 목록을 설정하고 총학생회의 부장과 신문방송국의 부장을 소속 단체로 구별한다. 최고 책임자의 구체 권한 묶음은 확인된 예산 관리 책임을 바탕으로 정한다.
- 학과협의회의 학과→학년→반은 담당 범위다. 그 밖의 부서·개별 동아리의 실제 구성과 자료별 열람 범위는 O-13에서 구체화한다. 담당자 변경과 소속 단위 변경을 구분하고 같은 상위 소속 안의 단위 중복 생성을 막는다(Q45).
- 첫 버전은 담당자 중심이다. 일반 학생·동아리원 전체의 일괄 가입을 목표로 하지 않는다. 동아리원 등이 운영 담당자로 지정되는 경우와 필요한 역할은 추가 결정한다.
- 학생성공센터 담당 교직원은 학생의 학년도별 소속·임기와 구분하여 단체별 담당 범위와 유효기간을 부여하는 안을 검토한다.
- 담당 교직원의 업무 권한과 개발·배포를 수행하는 플랫폼 운영 권한은 별도로 지정한다.
- 예산 관리 책임자는 교체할 수 있으나 조직의 예산·지출·증빙 기록은 그대로 보존한다. 개인이 예산을 보유·관리한다는 설명을 데이터의 개인 소유권으로 바꾸지 않는다.
- 간부의 회계 입력 권한은 별도 부여한다. 일반 지출 본인 확인은 허용하고 선생님이 전체 정산을 확정한다. 모든 지출의 사전 결재를 요구하는 구조로 확대하지 않으며 초과분은 해당 단체 최고 책임자가 확인하되 그 책임자 본인 집행 건은 선생님이 확인한다(DM-C03). 처리 결과·후속 절차는 추가 결정한다.
