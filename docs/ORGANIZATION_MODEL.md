# 연이음 조직 구조·운영 주체

버전 0.4 / 2026-11-11, Asia/Seoul. 근거는 사용자가 직접 설명한 학교 운영 구조와 상세 직책·권한 부여 설명(S7, S9, S10~S12)이다. 공식 규정·학교 승인·시스템 권한을 별도 검증했다는 뜻은 아니다.

## 1. 확인된 사실

- 학교: 연암공과대학교.
- 학생자치기구는 총학생회·학과협의회·신문방송국·연합동아리의 4개 단체다.
- 각 단체에 최고 책임자 1명이 있고, 그 아래 구성은 단체마다 다르다. 아래 표와 관계도는 S9의 상세 설명을 반영한다.
- 학생성공센터 담당 선생님이 포털의 관리자다. 각 단체 최고 책임자 권한을 부여한다.
- 첫 버전은 담당자 중심으로 사용하며, 최고 책임자는 자기 단체의 하위 역할을 부여할 수 있다.
- 예산은 각 단체의 최고 책임자가 보유하거나 관리한다.
- 학회장은 부학회장·반대표 역할을 직접 부여한다.
- 의장(학과협의회장)은 자기 학과의 학회장을 겸한다. 의장과 그가 맡고 있는 자기 학과의 학회장은 동일 인물이며, 의장은 이 두 역할을 동시에 맡는다.

| 단체 | 최고 책임자 직책 | 하위 구성 | 확인된 예산 책임 |
|---|---|---|---|
| 총학생회 | 학생회장 | 부장 → 차장 | 최고 책임자가 보유 또는 관리 |
| 학과협의회 | 의장 | 학회장 → 부학회장 → 반대표 | 최고 책임자가 보유 또는 관리 |
| 신문방송국 | 국장 | 부장 → 차장 | 최고 책임자가 보유 또는 관리 |
| 연합동아리 | 연합동아리장 | 일반동아리장 → 동아리원 | 최고 책임자가 보유 또는 관리 |

## 2. 관계도

아래는 조직의 구성 관계다. 별도로, S10에서 역할 부여 흐름은 담당 선생님→4개 최고 책임자→각 단체 하위 담당자로 확정했다. S11에서 학회장→부학회장·반대표 역할 부여를 추가 확정했고, 그 밖의 하위 담당자 재위임과 문서·회계 기능은 미정이다. 의장은 자기 학과 학회장을 겸한다(S12). [역할·권한 명세](ACCESS_CONTROL.md)를 함께 참조한다.

```text
연암공과대학교
└─ 학생성공센터 — 담당 선생님
   ├─ 담당: 총학생회
   │        └─ 학생회장
   │           └─ 부장
   │              └─ 차장
   ├─ 담당: 학과협의회
   │        └─ 의장 (자기 학과 학회장 겸임)
   │           └─ 학회장
   │              └─ 부학회장
   │                 └─ 반대표
   ├─ 담당: 신문방송국
   │        └─ 국장
   │           └─ 부장
   │              └─ 차장
   └─ 담당: 연합동아리
            └─ 연합동아리장
               └─ 일반동아리장
                  └─ 동아리원
```

직책의 연결 순서는 사용자 설명대로 확인했다. 각 단계의 인원수, 부서별 부장·차장 구성, 학과별 학회장·부학회장 및 학년·분반별 반대표 구성, 개별 동아리별 권한 경계는 아직 확인하지 않았다(O-13). 위 연결을 지출 승인 순서나 상위 직책의 모든 하위 자료 열람권으로 해석하지 않는다. 네 단체의 관계를 총학생회 산하 구조로 가정하지 않는다.

## 4. 데이터·권한 설계 제안

- 의장(학과협의회장)과 자기 학과 학회장은 동일인의 겸임이다. 두 역할의 담당 범위·권한 부여 기록·유효기간을 분리해 표현하는 안을 적용한다. 한 사람이 둘 중 한 역할을 내려놓는 경우의 승계·회수는 추가 결정한다.
- 직책과 시스템 권한을 구분한다. 단체별 직책 목록을 설정하고 총학생회의 부장과 신문방송국의 부장을 소속 단체로 구별한다. 최고 책임자의 구체 권한 묶음은 확인된 예산 관리 책임을 바탕으로 정한다.
- 학과·학년·분반·개별 동아리별로 자료를 나눌 필요가 확인되면, 4개 최상위 단체 아래 소속 단위와 해당 범위의 권한을 추가하는 안을 검토한다. 하위 단위의 개수·관계·권한은 O-13에서 결정하며 현재 직책만으로 자동 생성하지 않는다.
- 첫 버전은 담당자 중심이다. 일반 학생·동아리원 전체의 일괄 가입을 목표로 하지 않는다. 동아리원 등이 운영 담당자로 지정되는 경우와 필요한 역할은 추가 결정한다.
- 학생성공센터 담당 교직원은 학생의 학년도별 소속·임기와 구분하여 단체별 담당 범위와 유효기간을 부여하는 안을 검토한다.
- 담당 교직원의 업무 권한과 개발·배포를 수행하는 플랫폼 운영 권한은 별도로 지정한다.
- 예산 관리 책임자는 교체할 수 있으나 조직의 예산·지출·증빙 기록은 그대로 보존한다. 개인이 예산을 보유·관리한다는 설명을 데이터의 개인 소유권으로 바꾸지 않는다.
- 간부의 지출 입력 위임, 최고 책임자의 승인, 담당 선생님의 최종 승인 등은 후보 흐름이다. 사용자가 실제 절차를 설명하기 전 확정하지 않는다.
