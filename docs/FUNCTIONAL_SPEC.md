## 1. 분류와 상태

사용자가 요청한 필수·부가·확장 분류의 제안 초안(P)이다. 기능별 우선순위·상세 동작은 검토 후 확정한다. 기존에 사용자에게 확인된 사실(C)을 축소하거나 미정인 운영 절차를 새로 확정하지 않는다. 모든 항목은 현재 미구현이다.

| 분류 | 의미 | 적용 시점 제안 |
|---|---|---|
| 필수 M | 자료·예산·권한·인수인계의 핵심 업무를 완료하고 기록을 보호하는 데 필요한 기능 | 첫 버전 |
| 부가 A | 핵심 업무를 더 편리하게 수행하도록 돕는 기능. 없어도 핵심 흐름은 완료 가능 | 필수 완료 후, 시간·사용자 요구에 따라 |
| 확장 X | 새로운 업무 영역·연동·고급 자동화를 추가하는 기능 | 시범 사용 후 우선순위 재평가 |

기능 ID는 이 문서의 세부 항목이며 기존 F-01~10을 대체하지 않는다. M/A/X는 우선순위, C/R/P/O는 결정 상태다. 보안·보존·백업·복구 등 공통 요건은 부가 기능으로 미루지 않는다.

확정된 전제:

- 연암공과대학교의 총학생회·학과협의회·신문방송국·연합동아리 4개 단체를 대상으로 한다.
- 첫 버전은 담당자 중심으로 사용한다. 담당 선생님은 서비스 관리자이며 4개 최고 책임자 권한을 부여한다.
- 최고 책임자는 자기 단체의 하위 역할을 부여하고 학회장은 부학회장·반대표를 직접 지정한다.
- 의장(학과협의회장)은 자기 학과 학회장을 겸한다. 하나의 계정이 두 역할을 함께 가진다.
- 예산은 각 단체 최고 책임자가 보유·관리한다. 담당 선생님의 자료 열람·회계 결재 범위와 실제 지출 승인 절차는 미정이다.

M-04의 파일 검증·처리 상태·실패 복구는 필수다. SQS 등 구체 AWS 서비스는 아키텍처 선택이며 기능 우선순위와 별개다. 과제의 실제 AWS 연계 검증은 기존 5단계·T-12~15·8개 완료 조건을 유지한다.

## 6. 첫 버전 완료 범위와 다음 결정

첫 버전 완료 제안은 M-01~12, 위 공통 요건, 기존 [8개 완료 조건](ACCEPTANCE.md)을 모두 만족하는 기준이다. 로컬 기능 완성과 실제 AWS 통합·과제 완성은 구분한다. A/X가 미구현이어도 이 범위를 충족하면 첫 버전 완료를 판정할 수 있다. 실제 학교 시범 운영에는 별도 운영 게이트가 추가로 필요하다.

사용자와 다음을 검토해 분류를 확정한다.

1. 공지·대시보드·알림 중 첫 버전의 필수로 올릴 항목이 있는지.
2. M-09의 지출 검토가 사전 승인인지 사후 정산 확인인지, 누가 어떤 단계에서 검토하는지.
3. 각 자료·회계 기능을 최고 책임자와 하위 담당자에게 어떻게 나눌지, 선생님의 열람 범위.
4. 임기·인수 확인·역할 회수, 파일 형식·용량, 학과·반·개별 동아리 범위.

위 결정은 개발 브리프 O-01~04/08~10/12~13과 함께 갱신한다. 분류 초안을 작성했다는 이유로 사용자 승인이 필요한 미정 운영 정책을 확정하지 않는다.
