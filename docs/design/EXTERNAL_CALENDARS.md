# 공식 학사일정·공휴일 연동

2026-11-21 사용자 요청 C: [연암공과대학교 학사일정](https://eng.yc.ac.kr/www/scheduleList.do)과 대한민국 공식 공휴일을 기존 캘린더에 자동 표시한다. 아래 갱신·저장·표시 세부는 로컬 구현 선택 P다.

## 출처와 범위

- 학교는 지정한 HTTPS 페이지의 학년도 목록을 사용한다. 3월~다음 해 2월의 12개 월 구성이 완전한지 확인하고 월/연도 경계·기간 종료일 포함을 한국 시간의 종일 일정으로 바꾼다. 요청 학년도가 아직 게시되지 않았거나 구조/기간/제목 검사가 실패하면 기존 캐시를 지우지 않는다.
- 공휴일은 [한국천문연구원 특일 정보](https://www.data.go.kr/data/15012690/openapi.do)의 `getRestDeInfo` 월별 XML 응답을 사용한다. `resultCode=00`, 전체 건수·실제 항목 수·조회 연월·날짜·휴일 여부를 검사하고 `isHoliday=Y`인 항목만 표시한다. 월의 정상적인 0건 응답과 API 오류를 구분한다. 국가기념일·학교 휴무일·일반 토요일을 임의로 국가 공휴일로 계산하지 않는다.
- 공식 API 인증키가 없으면 ‘공휴일 API 인증키 설정 필요’를 표시한다. 학교 목록이나 비공식 달력으로 국가 공휴일을 대신 채우지 않는다. 일요일은 달력의 기존 요일 표시를 유지하며 매주 별도의 ‘공휴일’ 이벤트를 만들어 넣지 않는다.
- 학교와 공휴일은 서로 다른 공개 출처다. 같은 휴일이 학교 목록에도 있을 수 있으며 출처별 표시/숨김으로 구분한다. 같은 출처 안에서는 날짜·기간·제목으로 중복을 방지한다.

## 자동 갱신과 보존

현재 단일 로컬 API 프로세스가 켜져 있는 동안, 시작 시와 매시간 현재/가까운 기간을 검사한다. 성공한 원본은 24시간 이후 다시 수집하고 실패는 1시간 후 재시도한다. 화면에서 새 기간을 열 때 필요한 학년도·월도 자동 확인하며, 열린 화면은 5분마다 서버 캐시를 다시 읽는다. 서버 종료 중 갱신·OS 작업 예약·외부 캘린더 양방향 동기화·AWS 배포는 구현하지 않았다.

선생님은 ‘공식 일정 새로 확인’을 요청할 수 있다. 수동 요청도 같은 출처/기간에 1분 간격을 적용한다. 학생은 수동 강제 갱신 권한을 얻지 않으며 일반 조회가 기존 캐시 정책을 따른다.

`calendar_external_events`는 출처·학년도/월 묶음·외부 키·제목·종일 기간·출처 URL·활성 여부·확인 시각을 저장한다. `calendar_external_sync`는 각 묶음의 마지막 시도/성공·안전한 오류 안내·현재 건수를 저장한다. 사용자 `calendar_events`와 분리하고 삭제·수정·임기 변경을 연쇄 적용하지 않는다. 완전한 새 원본을 검증한 뒤 같은 묶음만 트랜잭션으로 갱신한다. 원본에서 사라진 항목은 비활성으로 남겨 기록을 보존한다. 사용자 일정·자료·예산·인수인계는 수정하지 않는다.

수집 주소는 서버에 고정한 학교·공식 API HTTPS 주소뿐이며 사용자 URL을 받아 요청하지 않는다. 브라우저 인증 쿠키·자료 파일·사용자 정보는 외부 요청에 전달하지 않는다. 요청별 10초 전체 제한·8초 통신 제한·응답 2 MiB·XML 엔터티 거절과 출처/묶음별 동시 실행 잠금을 적용한다. 인증키·인증키가 붙은 API 주소·원문 오류는 응답/DB/화면/로그에 출력하지 않는다. 다중 서버의 분산 갱신 제어는 후속이다.

## 화면과 권한

현재 유효한 캘린더 범위를 가진 활성·인증 계정과 선생님에게 공개 출처를 제공한다. 조회/갱신 후 세션·현재 역할을 다시 검사한다. 기존 조직의 내부 일정·참여자·자료·회계 범위를 넓히지 않는다.

사이드바 ‘공식 일정’에서 학교/공휴일을 따로 표시·숨김하고 확인 시각·연동 상태·공식 출처를 볼 수 있다. 가져온 일정은 종일 막대로 표시하며 드래그·편집·삭제·복사를 제공하지 않는다. 클릭 시 읽기 전용 상세와 공식 원본 링크를 제공한다. 출처의 정정은 원본 갱신을 통해 반영한다. 현재 이벤트 검색은 기존 사용자 일정 대상이며 공식 일정은 보고 있는 기간의 달력/목록에서 확인한다.

## 공휴일 인증키 설정

1. 공공데이터포털에 로그인하고 위 ‘한국천문연구원 특일 정보’에서 활용신청한다.
2. 승인된 서비스의 일반 인증키를 확인한다. 키는 Git·문서·채팅·웹 설정에 저장하지 않는다.
3. API를 실행할 PowerShell 창에서 아래 환경변수를 설정하고 기존 API를 종료한 뒤 같은 DB로 다시 실행한다. `.env` 자동 로딩은 추가하지 않았다.

```powershell
cd D:\Tak\yeonieum
$env:YEONIEUM_HOLIDAY_SERVICE_KEY = Read-Host '공공데이터포털 인증키'
$env:YEONIEUM_EXTERNAL_SYNC = '1'
.\apps\api\.venv\Scripts\python.exe -m uvicorn yeonieum.main:create_app --factory --app-dir apps/api/src --host 127.0.0.1 --port 8000
```

인증키 입력은 명령 문자열에 직접 쓰지 않는다. `YEONIEUM_EXTERNAL_SYNC=0`은 외부 통신과 자동 갱신을 끈다. 기존 캐시와 사용자 자료는 삭제하지 않는다. 실행/검사 코드는 기존 로컬 경로를 유지한다.

## 구현·검증

API `modules/calendar/external_parsers.py`가 원본 형식 검증, `external_calendar.py`가 수집·캐시·조회·갱신을 맡는다. 웹 `features/calendar/ExternalCalendars.tsx`가 상태·필터·읽기 전용 상세를 맡고 기존 월/주/일 화면을 재사용한다. 추가 의존성은 없다.

`test_external_calendar.py`는 가상 원본으로 연도/월 경계·휴일 여부·불완전/위험 응답·중복·원본 정정·오류 시 기존 자료/사용자 일정 보존·권한·인증키 누락·기간 제한을 검증한다. E2E는 네트워크 수집을 명시적으로 끄고 가상 API 응답으로 표시·필터·원본 링크·편집 차단·갱신 실패 보존을 확인한다. 실제 공휴일 API 성공 검증은 인증키 설정 전 미수행이다. 최신 수치는 PROTOTYPE.md를 따른다.
