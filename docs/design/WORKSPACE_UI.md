# 연이음 워크스페이스 UI

## 요청과 범위

사용자가 첨부한 Hackle 화면의 상단 헤더·왼쪽 그룹 메뉴·빠른 시작 카드·현황 패널 구성을 참고한다. 연이음의 학교 심볼, Pretendard, 리넨 팔레트(#F7F3EE/#E6DED4/#C9BFB4/#6B625B/#1F1D1B)는 유지한다. 참고 서비스의 브랜드·제품 기능·파란색·가짜 통계는 가져오지 않는다.

이번 요청은 기존 기능의 화면 배치·탐색 개선이다. 자료실 인터뷰의 분류·권한·공용 공간·학년도/상시 자료 구조는 이번 UI 요청으로 확정하지 않는다. 기존 자료실·회계·인수인계의 임시 P 정책과 데이터는 변경하지 않는다.

## 구성

- 전체 너비의 상단 헤더: 연이음 브랜드, 학교 표시, 현재 사용자, 로그아웃.
- 왼쪽 메뉴: 워크스페이스(대시보드), 기록과 업무(자료실·예산/정산·인수인계), 운영 관리(조직/권한·활동 이력).
- 데스크톱 메뉴 접기·펼치기. 접힌 상태에서도 접근 가능한 이름·선택 상태·권한 제한을 유지한다.
- 모바일은 6개 업무 메뉴를 3열로 표시해 별도 메뉴 열기 없이 이동한다.
- 대시보드의 빠른 시작 카드 3개는 실제 자료실·예산/정산·인수인계 화면으로 이동한다. 카드의 그림은 업무를 설명하는 장식이며 실제 통계나 업로드 기록이 아니다.
- 후속 캘린더 요청으로 담당자·역할 요약, 임기/상태 차트, 담당 범위·연락처 표를 대시보드에서 제거했다. 현재는 [업무 캘린더](CALENDAR.md)를 표시한다. 조직·권한 관리 기능과 기존 담당 범위 인가는 유지한다.
- 본문 바로가기, 키보드 포커스, 선택 메뉴 표시, 작은 화면 줄바꿈, 움직임 감소 설정을 지원한다.

## 구현 위치

- apps/web/src/features/workspace/WorkspaceShell.tsx: 공통 헤더·메뉴·페이지 틀.
- apps/web/src/features/workspace/WorkspaceIcon.tsx: 코드 기반 선형 SVG 아이콘.
- apps/web/src/features/workspace/workspace.css: 기존 색상 토큰을 사용하는 레이아웃·반응형·빠른 시작 카드 스타일.
- apps/web/src/features/dashboard/QuickStart.tsx: 실제 업무 진입 카드.
- 기존 Portal은 업무 상태·권한·등록/수정 흐름을 유지하고 공통 틀을 사용한다.

## 검증 기준

기존 조직·권한·자료실·회계·인수인계 브라우저 흐름을 회귀 검사한다. workspace.spec.ts에서 메뉴 접기 상태 이동, 세 업무 카드의 목적지, 로그아웃, 1600px 및 768/390/320px 화면, 리넨 토큰 유지와 브라우저 오류를 확인한다. 스크린샷은 별도 가상 DB로 실행한 테스트 결과만 local-data/preview에 저장하며 Git에 포함하지 않는다.

커밋·푸시·AWS 배포는 수행하지 않는다.
