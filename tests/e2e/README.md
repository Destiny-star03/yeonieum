# 사용자 흐름 테스트

2026-11-21 누적 전체 검증은 **34개 통과**다. 모바일 예산 순서 검증은 앞선 흐름이 추가한 단체 수에 의존하지 않도록 첫 두 카드를 화면 안으로 스크롤한 뒤 손잡이로 드래그한다. 아래 이전 수치는 각 보완 당시의 기록이다.

`external-calendar.spec.ts` 2개는 출처별 표시/숨김, 읽기 전용 상세·공식 링크, 인증키 대기 안내, 수동 갱신과 실패 시 마지막 일정 보존, 모바일 배치를 검증한다. `calendar.spec.ts` 8개와 함께 10개가 통과했다. E2E API는 `YEONIEUM_EXTERNAL_SYNC=0`으로 외부 수집을 끄며, 공식 일정 응답은 가상 데이터로 대체한다. 실제 학교/공휴일 서버의 가용성을 브라우저 통과로 주장하지 않는다.

`documents.spec.ts` 8개는 기존 파일·버전·휴지통·복원에 연도/단체 카드·중첩 폴더·형식 필터·카드/목록·상세 패널과 개인 자료 격리/명시적 단체 공유를 포함한다. 간결한 등록창의 드래그·키보드 선택, 자동 제목·직접 입력 유지, 선택 오류·교체·제거, 선택 사항 없이 저장도 검증한다. 폴더 경로와 등록창이 320/390px에서 가로 넘침 없이 표시되는지 확인한다.

웹과 API를 함께 사용하는 실제 업무 흐름을 Playwright로 검증한다. `access.spec.ts`는 조직·권한, `documents.spec.ts`는 일반 자료실, `finance-handover.spec.ts`는 로컬 예산·증빙·검토와 인수자 필수 확인 흐름을 검증한다.

2026-11-21 반복 보완: 캘린더는 8개로 확장했다. 빈 공간 클릭의 기본 패널 복귀·폐기 취소·저장 중 보호와 기존 막대/시간축 드래그 구분, 사용자 지정의 여러 요일·격주·횟수/날짜 종료·취소·모바일을 포함한다. 사용자 지정 모달의 완료만으로 일정이 저장되지는 않는다.

2026-11-21 표시 보완: 예산·인수인계는 4개, 캘린더는 6개다. 단체 순서의 카드/손잡이 드래그·방향키·초점·저장·잘못된 설정 복구와 색상 점 팝업의 선택/저장/기본색·키보드·모바일 배치를 추가 검증한다.

`finance-handover.spec.ts` 3개는 선생님의 연간 예산·현재 책임자 명시적 권한 부여, CSV 미리 읽기의 무차감·합계 확인 뒤 원본 증빙과 한 번의 차감, 증빙 전송 실패 후 재시도, 기존 전체 정산·인수 확인을 검증한다. 전체 검사에서 의장이 바뀔 수 있어 현재 유효한 의장을 조회하며 각 예산 흐름은 별도 연도를 사용한다. 캘린더 다일 일정 검사는 토요일의 주 경계에서 월간 막대가 나뉘고 주간의 다음 기간으로 이어지는 경우도 확인한다.

`workspace.spec.ts`는 메뉴·업무 진입 카드·반응형 화면을, `calendar.spec.ts`는 일정·반복·편집 패널·검색·명령어·드래그·포털 리마인더를 검증한다. 드래그 테스트는 확대 보기에서 출발/도착 지점이 보이는 상태로 실행하고 재로딩 완료 후 새 좌표를 얻는다. 주말 숨김 검사에서는 실제 선택 날짜를 기준으로 표시 열 수를 계산한다.

로그인→조직/역할 선택→자료 등록·검색→예산·지출·정산→인수인계 흐름을 [수용 기준](../../docs/ACCEPTANCE.md)에 연결한다. 가상 자료와 권한이 다른 계정으로 검증하고, 단위·API 통합 테스트를 이곳에 중복 작성하지 않는다.

기본 테스트 포트는 API 8010·웹 5180이다. 시연 8000·5173과 분리하고 API·웹을 테스트가 시작한다. `YEONIEUM_E2E_API_PORT`, `YEONIEUM_E2E_WEB_PORT`로 테스트 포트를 바꿀 수 있다. 실제 DB를 재사용하지 않는다. 가상 DB와 불투명 파일 폴더·스크린샷·트레이스는 Git 제외 `local-data`/`test-results`에만 둔다.

조직·권한의 실제 브라우저 흐름은 `access.spec.ts`다. 실행 도구와 앱 UI 로그인 보조 함수는 웹 앱의 Playwright 설정·`apps/web/tests/browser-fixtures.ts`가 소유한다. 저장소 루트에서 `npm run test:e2e --prefix apps/web`로 실행한다. 이 검사는 독립 가상 SQLite DB에서 로컬 웹과 API를 연결하며 AWS 검증이 아니다.
