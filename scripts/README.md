# 개발·운영 스크립트

반복해서 사용하는 개발·데이터 준비·검증·운영 작업이 생길 때 스크립트를 추가한다. 현재 `check_git_policy.py`가 커밋 제목·브랜치·PR 경로와 GitHub 이벤트의 새 커밋을 읽기 전용으로 검사한다. `tests/unit/test_git_policy.py`에서 실제 임시 Git 이력으로 검증한다.

명령 이름·입출력·필요 권한·실패 시 동작을 명시하고 비밀정보를 내장하지 않는다. 일회성 임시 코드나 복제한 빌드 명령을 계속 쌓지 않는다. 현재 공통 검사는 루트의 pre-commit 설정을 사용한다.

자세한 명령과 규칙은 [Git 협업 규칙](../docs/GIT_WORKFLOW.md)을 따른다.
