## 현재 상태

작업 폴더는 `D:\Tak\yeonieum`다. 학교는 **연암공과대학교**, 현재 기본 등록 단체는 **총학생회·학과협의회·신문방송국·연합동아리·모니터링단**이다. 학생성공센터 담당 선생님이 서비스 관리자다. 첫 버전은 담당자 중심이며 담당 선생님이 최고 책임자 권한을 부여하고, 최고 책임자는 자기 단체 하위 역할을 부여한다. 학회장은 부학회장·반대표 역할을 직접 부여하며 의장(학과협의회장)은 학회장들의 투표로 학회장 중 선출되어 자기 학과 학회장을 동일 공식 임기로 겸한다. 반대표 담당 범위는 학과→학년→반이고 학회장 자격 종료 시 의장도 종료한다. 일반 지출 본인 확인은 별도 권한·범위 안에서 허용하며 전체 정산은 선생님이 미처리 항목을 처리한 뒤 확정한다. 학회장 외 재위임은 첫 버전 제외다.

- 원 대화의 전체 제공 기록을 확인하고 개발 문서를 작성했다.
- 원격 저장소: [Destiny-star03/yeonieum](https://github.com/Destiny-star03/yeonieum). 개발 통합은 `develop`, 작업은 기능 브랜치, 운영 기준은 `main`이다. AWS 계정·배포 환경은 아직 미지정이다.
